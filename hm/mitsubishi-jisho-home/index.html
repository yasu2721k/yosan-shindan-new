三菱地所グループの位置づけ

三菱地所ホームは、日本を代表する総合不動産デベロッパー「三菱地所」の住宅部門。丸の内を中心としたオフィスビル、商業施設、マンション（ザ・パークハウス）まで手がける三菱地所グループの一員として、グループのブランド力・技術力・信頼性を背景に注文住宅を展開している。

少量受注の特徴

年間受注棟数は約500〜600棟と、大手ハウスメーカー（積水ハウス約1万棟、一条工務店約1.6万棟）と比較すると圧倒的に少ない。その分「1棟1棟に丁寧に向き合う」姿勢が特徴で、設計の自由度と施主との打合せの密度が高い。1棟あたりの平均単価は6,000万円超（2021年度上期実績）と高額帯に位置する。

一言で言うと？

三菱地所グループの信頼を背景に、全館空調「エアロテック」を全棟標準搭載する、少量受注・高品質路線のハウスメーカー。首都圏・関西圏限定で、1棟ずつ丁寧に設計・施工する「質」重視の家づくりが最大の特徴。

過去の地震での実績

阪神・淡路大震災（1995年）では、2×4（ツーバイフォー）工法の住宅について、社団法人日本ツーバイフォー建築協会の調査で損傷軽微の割合が高かったと報告されている。ただし三菱地所ホーム固有のデータ（全壊・半壊率など）は公式一次情報で未確認のため、本項は業界全体の2×4工法の耐震実績として参照されたい。

⑨ エアロテック全館空調 徹底解説

1989年に高齢社会に向けた住宅の調査研究から開発を開始し、1995年に発売。2025年で30周年を迎えた、三菱地所ホームの代名詞ともいえる全館空調システム。

エアロテックが選ばれる5つの理由

  1. 家中どこでも快適温度 — 1台のシステムで家全体を24時間365日冷暖房。リビング・寝室はもちろん、廊下・脱衣室・トイレまで温度差がない。ヒートショックのリスクを大幅に低減
  2. 部屋ごとに温度調整可能 — VAV＋ABC（三菱特許技術）により部屋ごとの個別温度設定が可能（例：リビング25℃、寝室22℃）
  3. 空気がキレイ — 高性能除塵フィルターが花粉・カビ胞子を約97%カット。24時間換気で常に新鮮な空気を供給し、臭気は約1/3の時間で減衰
  4. 省エネ性能No.1 — COP4.43は床置き型全館空調で業界最高水準。個別エアコン比で年間電気代約50%カット（年間約48,000円 / 東京・45坪想定 / 2025年3月時点の試算）
  5. 見た目スッキリ — 各部屋にエアコンが不要。室外機も2台で済む

エアロテックの注意点

注意点詳細
導入コスト本体価格に含まれるが、エアロテック分のコストは坪単価に反映されている
冬場の乾燥全館空調の特性上、冬場は室内が乾燥しやすい。加湿器の併用を推奨
除湿効果夏場の除湿効果がやや弱いという声あり
足元の冷え床暖房ではないため、冬場に足元の冷えを感じるケースも（スリッパ・ラグで対策可能）
故障時全館空調が故障すると家全体の空調が止まる。ただし24時間サポートで対応
交換費用15〜20年後の交換時に100〜150万円程度の費用が見込まれる

後悔①：対応エリアが限定的で、地元では建てられなかった

首都圏（東京・神奈川・千葉・埼玉・茨城）と関西圏（大阪・京都・兵庫・奈良）のみ。転勤や実家の近くに建てたい場合、エリア外で検討できない。

→ エリア内であることを最初に確認する。エリア外の方は住友林業・三井ホーム等を検討

後悔②：エアロテックの冬場の乾燥がひどい

全館空調の特性上、冬場の室内湿度が30〜40%に低下しやすい。肌荒れ・のどの痛み・静電気の発生を報告する声。加湿器を導入したが、点検で不具合が発覚し交換が必要になった事例も。

→ 加湿器の併用を前提に計画する。高性能な据置型加湿器を推奨

後悔③：坪単価が想定以上に高くなった

ONE ORDERは坪単価90万円〜が目安だが、こだわりを入れると120〜130万円超になることも。標準仕様の選択肢が少なく、オプション追加で費用が膨らみやすい。「最初の見積もりから1,000万円以上上がった」という声も。

→ 予算上限を最初に明確に伝える。SMART ORDER Fitも視野に入れる

後悔④：標準仕様のグレードに不満

標準仕様のトイレ・設備のグレードが価格帯に見合わないと感じた施主も。「この価格ならもっと良いものが標準であるべき」という期待とのギャップ。

→ 標準仕様の詳細を契約前に確認し、必要なアップグレードは見積もりに含める

後悔⑤：エアロテックの故障時に家全体の空調が止まる

エアロテックが1台のシステムで全館をまかなうため、故障時のリスクが集中。修理対応が翌日以降になるケースも（24時間サポートはあるが即日修理は難しい場合も）。

→ 5年点検パックに加入し、定期メンテナンスを確実に実施する

後悔⑥：担当者の計算ミス・設計ミス

一部の口コミで「計算ミスがあった」「エアロテックの不具合対応が遅い」との声。少量受注のため1人の担当者が多くの工程を兼務するケースがあり得る。

→ 打合せの議事録を毎回確認する。不安があれば担当者の変更を相談

⑬ FAQ

三菱地所ホームは高いですか？
全体平均の坪単価は約103〜123万円で、大手の中では高価格帯。ただしエアロテック（全館空調）が標準搭載されているため、他社でオプション追加した場合と比較すると価格差は縮まる。SMART ORDER Fitなら1,490万円〜も可能。
エアロテックの電気代は高いですか？
年間冷暖房費は約48,000円（東京・45坪想定 / 2025年3月時点の試算）。個別エアコンの住宅（約97,000円）と比較して約50%カット。24時間つけっぱなしでも経済的。
エアロテックは冬に乾燥しますか？
はい。全館空調の特性上、冬場は室内湿度が下がりやすい。加湿器の併用を推奨。
対応エリアはどこですか？
首都圏（東京・神奈川・千葉・埼玉・茨城）と関西圏（大阪・京都・兵庫・奈良）。一部地域を除く。全国展開はしていない。
間取りは自由に決められますか？
ONE ORDERは完全自由設計。一級建築士が直接担当し、狭小地・変形地にも柔軟に対応。一条工務店のような「ルール」的制約は少ない。
木造は地震に弱くないですか？
ツーバイネクスト構法で全棟耐震等級3。独自のハイプロテクトウォール（壁倍率6〜10倍）搭載。阪神・淡路大震災の際、業界全体としての2×4工法は損傷軽微の割合が高かったと日本ツーバイフォー建築協会から報告されている（三菱地所ホーム固有の全壊・半壊データは公式一次情報で未確認）。さらに免震システム「ピアニシモ」もオプションで対応可能。
値引き交渉はできますか？
紹介割引（オーナー紹介: 3〜5%、提携企業: 約3%）が活用できる。ただし紹介割引は展示場訪問前に手続きが必要。一度でも接点を持つと適用外になるため注意。
SMART ORDER Fitと ONE ORDERの違いは？
SMART ORDER Fitはプロ厳選プランから選ぶ定額制（1,490万円〜）で、短工期・低コスト。ONE ORDERは完全自由設計で、間取り・仕様を全てオーダーメイド。エアロテックはどちらも標準。
三菱地所ホームの家は資産価値が高いですか？
三菱地所グループのブランド力と高品質な施工は、中古市場でも一定の評価を得やすい。ただしエリア限定（首都圏・関西）のため、リセールは立地条件に大きく依存する。
ROBRAとは何ですか？
世界初の特許技術「FMT構法」を採用した木造ブランド。集成材厚板パネル＋鉄骨梁のハイブリッドで、柱や梁に捉われない自由空間を実現。住宅だけでなくクリニック・店舗にも対応。RC造比で約2割コストダウン。
エアロテックの寿命は何年ですか？
機器保証は最大10年。実際の耐用年数は15〜20年程度。交換費用は100〜150万円が目安。5年点検パックで定期メンテナンスを行えば長寿命化が期待できる。
3階建ては可能ですか？
可能。木造3階建てにも対応しており、都市部の狭小地では3階建ての実績が豊富。
太陽光パネルは搭載できますか？
搭載可能。HOMETACTと連携し、発電量の可視化やエネルギーマネジメントもできる。
建築期間はどのくらいですか？
設備・仕様の打合せに2〜3ヶ月、着工から上棟まで約2ヶ月、引渡しまで全体で8〜15ヶ月が目安。土地探しを含めると2〜3年かかる場合も。
よく比較されるハウスメーカーは？
住友林業（木×自由設計）、三井ホーム（洋風デザイン）、一条工務店（断熱最優先）、積水ハウス（永年保証・全国対応）が最多の比較対象。
